# Escape Room — План загадок

## Сценарий: "Выход из тёмной комнаты"

### Пазл 1 — Лампа (раскачай)
- Комната тёмная. Раскачай лампу триггером — она разгорается, освещает комнату.
- **Скрипт**: XRTriggerRotate (уже есть)
- **Объект**: лампа в darkRoom

### Пазл 2 — Лиса (потряси)
- Возьми лису, потряси — из неё выпадает ключ.
- **Скрипт**: ShakeDetector
- **Объект**: лиса в darkRoom + key.obj

### Пазл 3 — Ключ (измени форму)
- Ключ не подходит к замку. Нужно растянуть/деформировать ключ до правильной формы.
- **Скрипт**: ShapeValidator + SplatDeformate
- **Объект**: key с GS-деформацией
- Главная демонстрация GS-Verse: игрок физически меняет форму объекта руками в VR.

### Пазл 4 — Замок (вставь ключ)
- Вставь правильно деформированный ключ в замок — дверь открывается.
- **Скрипт**: KeySlot + Door
- **Объект**: KeySlot (замок) + Door

---

## Упрощённый вариант (для начала)
Пазл 2 + Пазл 4 (без лампы и деформации ключа).
Потом добавляем остальные.

## Как добавить объект (mesh) в сцену darkRoom

### Добавление key.obj
1. `key.obj` уже лежит в `Assets/RoomScenes/darkRoom/`
2. Открой сцену `364.unity`
3. Перетащи `key.obj` из Project окна в Hierarchy или Scene view
4. Расположи рядом с лисой (Fox) через Transform в Inspector

### Создание золотого материала для ключа
1. В **Project** окне, правой кнопкой по папке `Assets/RoomScenes/darkRoom/` → **Create → Material**
2. Назови `KeyMaterial`
3. В **Inspector** настрой:
   - **Albedo** (цвет) — нажми на прямоугольник, введи `FFD700` (золотой)
   - **Metallic** — ползунок до **0.8**
   - **Smoothness** — ползунок до **0.7**
4. Выдели **Key** в Hierarchy
5. В Inspector: **MeshRenderer → Materials → Element 0** — перетащи `KeyMaterial` вместо `defaultMat`
6. Сохрани сцену (Ctrl+S)
