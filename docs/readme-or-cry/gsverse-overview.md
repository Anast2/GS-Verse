# GS-Verse — Что есть что

## GaMeS vs GS-Verse

### GaMeS (Gaussian Mesh Splatting) — алгоритм
Научный метод, придуманный другими исследователями. Привязывает Gaussian Splats к поверхности 3D меша. Благодаря этому при деформации меша (растяжение, сжатие) сплаты двигаются вместе с ним и объект продолжает выглядеть реалистично.

### GS-Verse — приложение
Наш проект. Использует GaMeS внутри, но добавляет:
- Unity интеграцию (рендеринг GaMeS в реальном времени)
- VR взаимодействие (контроллеры, grab, физика через XR Interaction Toolkit)
- Escape Room логику (пазлы, последовательность, события)

```
GaMeS (алгоритм)      = "как привязать сплаты к мешу"
GS-Verse (приложение)  = "VR мир где можно трогать и менять
                          Gaussian Splat объекты руками"
```

Аналогия: GaMeS — это двигатель, GS-Verse — это машина, в которую этот двигатель поставили.

## Структура репозитория

```
GS-Verse/
├── package/                  # GS-Verse как Unity пакет (ядро системы)
│                             # Переиспользуемая библиотека — можно подключить
│                             # к любому Unity проекту
│
├── projects/
│   └── GaussianExample/      # Unity проект, который ИСПОЛЬЗУЕТ пакет
│                             # Сцены, объекты, скрипты escape room
│                             # Это то что открываешь в Unity
│
├── notebooks/                # Colab ноутбук для подготовки ассетов
├── scripts/                  # Python-скрипты для подготовки ассетов
└── docs/                     # Документация
```

### package/ — библиотека (как плагин)
Код рендеринга Gaussian Splats, GaMeS интеграция, шейдеры. Можно подключить к любому Unity проекту.

### projects/GaussianExample/ — демо-приложение
Конкретный Unity проект с комнатами, VR взаимодействием и escape room логикой. Именно тут лежат сцены (darkRoom, bearRoom), объекты (лиса, ключ, лампа) и скрипты пазлов.

### notebooks/ — инструмент подготовки
Google Colab ноутбук для обучения GaMeS. Превращает картинку в Gaussian Splat для Unity.

### scripts/ — утилиты
Python-скрипты для конвертации и экспорта параметров.
